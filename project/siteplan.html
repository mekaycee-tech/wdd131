Website Planning Document

Local Architectural Landmarks & Cultural Heritage Guide

1. Site Name

Name: Urban Heritage Architecture Guide

Reason: This name directly tells visitors that the site focuses on historic and modern architectural landmarks in the local area[cite: 1].

Optional Domain: urbanheritageguide.org

2. Site Purpose

The site provides a guide highlighting local architectural landmarks[cite: 1]. It includes landmark galleries, historical information, an interactive travel estimator, and a contact form for visitor inquiries[cite: 1].

3. Target Audience Scenarios

  • Where can I find historical background and visiting information for local landmarks[cite: 1]?
  • How can I filter local landmarks by era or style to plan a visit[cite: 1]?

4. Color Schema

Here are the chosen colors and where they will be used on the website:

Primary Color: #1C3144 (Deep Slate Blue) - Used for Headers and Navigation
Secondary Color: #D00000 (Terracotta Red) - Used for Buttons and Highlights
Background Color: #F0F4F8 (Light Blue-Gray) - Used for Page Background
Text Color: #2B2D42 (Charcoal) - Used for Main Text

5. Typography

  • Heading Font: Georgia (Serif) - Gives headings a classic architectural look.
  • Body Font: Arial (Sans-serif) - Keeps reading clean and simple for all text.
